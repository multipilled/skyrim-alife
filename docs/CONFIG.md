## props.ltx

Loaded by `src/core/Config.cpp:197`.

> Smart terrain properties (Anomaly simulation_objects_props.ltx + smart terrain respawn params).
> base / territory / resource / surge / lair : what kind of target the place is for the sim board
> all                                       : any faction may pick it (Anomaly "all")
> <faction id> = n                          : extra target priority for that faction; a faction with n = 0 (and all = 0) never targets it
> owner = n                                 : extra priority for the place's default faction (the hold's side, or default_faction)
> max_population                            : squads that may be assigned (heading there or staying) at once
> default_faction = hold \| none \| <id>      : who holds it at the start ("hold" = the side holding the hold, see factions.ltx)
> faction_controlled                        : only the controlling faction's squads respawn here; control flips when others take it
> respawn = a, b                            : respawn entries -> sections [spawn_a] [spawn_b]
> respawn_idle / respawn_radius             : game hours between respawn attempts / minimum distance from the player
> (an overlay's respawn_idle is a floor: the place restocks no faster than that)
> monster_population                        : at most this many monster squads at once (0 = only max_population): one pack per
> den, so the overflow fills the next empty lair (Anomaly's lairs fill up first)
> lair                                      : a monster lair: monster squads may always target it and fill lairs first (docs/MUTANTS.md)
> monster = n                               : any monster squad may pick it (Anomaly all_monster); `all` stays for people only
> [keyword_props] adds a section to every location that carries a keyword (numbers add up, respawn entries are appended),
> on top of its kind preset: that is how Nordic ruins become draugr lairs whatever the classifier called them.
> A [loc_<FormID hex>] section overrides one specific location (inherit a preset with :p_name).
